RAW DATA:
---------
yellow_tripdata_2016-03.csv
  • NYC TLC Yellow Taxi trip records for March 2016
  • 12,210,952 rows × 19 columns
  • We use 9 columns, ignore 10
  • Known anomalies: 71K zero-distance, 182K null coords, 21 >1000mi trips
  
od_hour_traveltime.csv
  • Hourly origin-destination travel time data
  • Support file for analysis

PROCESSED DATA:
---------------
nodes.csv
  • 87 graph nodes with demand-weighted centroids
  • Columns: node_id, lat, lon, trips, cell_i, cell_j
  • Grid: 0.01° (≈1.11 km), threshold: 2,000 trips

trips.parquet
  • 10,300,738 cleaned trips (84.36% retention)
  • Columns: o, d, km, dur_min, fare, date, hour, daytype, profile
  • 7 filters applied (6.64% dropoff bbox, 4.11% pickup bbox are largest)

distance.npz
  • 87×87 Geo distance matrix (km)
  • Median observed + rotated-L1 fallback
  • Circuity: 1.320 (road/straight)

traveltime.npz
  • 87×87×48 travel-time tensor (full month)
  • 48 profiles = 2 day types × 24 hours
  • Used by environment as "true physics"

traveltime_train.npz
  • 87×87×48 travel-time tensor (pre-test-week)
  • Forecaster trains on this (no future peeking)

traveltime_test.npz
  • 87×87×48 travel-time tensor (test week only)
  • Held out for evaluation

demand.npz
  • 87×87×744 request counts
  • 744 = 31 days × 24 hours
  • For forecaster training + driver placement

Given raw/yellow_tripdata_2016-03.csv, rebuild everything:

  python -m ltf.data.prepare       # builds nodes.csv, trips.parquet
  python -m ltf.data.graph         # builds distance.npz
